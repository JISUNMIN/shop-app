## Phase 11 - Queue Workflow

### What Changed
- 운영 보드를 큐 중심 화면으로 확장했다.
  - `전체 / 긴급 / SLA 초과 / 클레임 / 미배정 / 내 작업` 프리셋 큐 추가
  - 큐별 건수 표시
- 보드 필터를 강화했다.
  - 담당자 기준 추가 필터
  - 우선순위 필터
  - 정렬 옵션: 최신순 / 우선순위순 / SLA 임박순
- 운영 보드에 `지금 바로 처리할 주문` 섹션을 추가했다.
  - 현재 큐와 정렬 기준으로 우선 봐야 할 주문 3건을 별도 표시
- 주문 카드에 SLA 상태 배지를 추가했다.
  - `SLA 없음 / 정상 / 임박 / 초과`
- 운영 메타데이터 편집을 빠르게 만들었다.
  - `나에게 배정`
  - `SLA +1일`
  - `SLA +2일`
- 운영 상세 화면에도 같은 빠른 배정/SLA 액션을 붙였다.

### Why It Matters
- 이제 운영 보드가 단순 CRUD 목록이 아니라 실제 처리 순서를 잡는 워크 큐처럼 보인다.
- 포트폴리오에서 “운영 상태 관리”를 넘어서 “업무 우선순위와 SLA 기반 처리 화면”을 설계했다고 설명할 수 있다.
- 이후 담당자별 성과, SLA 리포트, 클레임 전용 큐로 확장하기 좋은 구조가 생겼다.
